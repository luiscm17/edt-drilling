# WellPlan reference material

The normative reconstruction target is the [OpenOil WellPlan capability roadmap](../../docs/gaps.md). Its supporting developer reference, [WellPlan engineering capabilities](../../docs/reference/wellplan-capabilities.md), summarizes documented workflows, selected equations, outputs, and model limits in repository-local prose.

The remaining files in this directory are supplementary research records, not product requirements or implementation instructions. The capability summary and roadmap are the durable sources for developer-facing scope.
